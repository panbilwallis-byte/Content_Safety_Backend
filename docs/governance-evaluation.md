# 价值分析与异常治理的真实评估

测试评估的「能力任务结果」列出已保存且当前令牌可访问的风险、价值和异常任务结果。来源名称带功能、数据集版本、模型、时间及任务编号。同一次分析的结果 ID 是其精确版本，不使用数据集的最新状态代替历史结果。

## 人工标准答案

标准答案填写在导入的数据记录中，随后创建固定数据版本，再从相应治理页面执行一次新的分析。不能从模型输出反推人工答案。

价值分析示例：

```json
{"text":"一段语料正文","language":"zh","reference_value_tier":"high"}
```

`reference_value_tier` 仅允许 `high`（高价值）、`medium`（中价值）、`low`（低价值）。这是价值档位，不是风险等级。人工应先按所用评分方案的标准标注。

异常治理示例：

```json
{"text":"一段语料正文","language":"zh","topic_label":"文化","reference_is_anomaly":false}
```

`reference_is_anomaly` 必须是 JSON 布尔值：`true` 表示异常，`false` 表示正常；字符串 `"false"`、数字 0/1 均不接受。标注范围应与选定异常检测方案一致。

这三个评估字段（含 reference_risk_level）在模型输入正文和异常检测 metadata 中均被排除。任务保存时另行冻结人工答案及价值评分方案。缺少答案的样本仍列出，但不纳入准确率分母；所有样本都无答案时，预检阻止创建任务并说明所缺字段。标注改变后必须创建数据版本并重新分析。

## 指标口径

| 来源 | 指标 | 计算方法 |
| --- | --- | --- |
| 价值分析 | 价值档位准确率 | 档位完全一致数 / 全部有人工档位的样本数 |
| 价值分析 | 高价值检出率 | 判为高价值的人工高价值样本数 / 全部人工高价值样本数 |
| 异常治理 | 异常识别准确率 | 正常/异常判断正确数 / 全部有人工异常标注的样本数 |
| 异常治理 | 异常检出率 | 正确检出的异常数 / 全部人工异常样本数 |
| 异常治理 | 正常样本误报率 | 被判异常的人工正常样本数 / 全部人工正常样本数 |

调用失败和不可评估仍计入有标签的分母，不计作正确；误报率涉及缺失判断时只能给出当前检出误报比例，结论为「无法判定」。分母为零时无数值且无法判定。默认准确率/检出率 ≥95%、误报率 ≤5%，仅为配置起点，正式要求应在指标管理修订。

异常指标仅评价检测结果，不证明字段修改建议修复成功。要验收修复，需要另行提供人工确认的修复结果和前后对照标准。

## 执行与留痕

在「测试评估 → 新建测试任务」选择「能力任务结果」，选中对应功能的一次结果，勾选该功能支持的指标，执行预检并创建，再启动任务。计算只引用冻结结果，不再调用模型。结果页面可查看逐条标准答案、预测、对错、是否计入分母及失败原因，并导出实际内容及其 SHA-256。

模拟样本结果、没有固定清单的历史结果、未冻结人工答案的历史价值/异常结果不能用于真实验收，来源提示会说明原因。补标注后应重新执行分析，而不是给旧结果直接添加答案。

部署后业务后端重启会补登五项指标。模型服务治理 worker 也需重启才能采用标签隔离和标准答案冻结逻辑；更新前的历史结果不会自动变成符合新要求的结果。无需数据库加列或迁移历史风险评估。
